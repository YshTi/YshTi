# 👋 Вітаю, я Тетяна Юшкевич

### Інженерка-програмістка | Full-Stack розробка · Наукові обчислення | PhD з фізики

Я інженерка-програмістка з досвідом у **full-stack веброзробці, наукових обчисленнях, моделюванні та розробці програмного забезпечення для роботи з великими обсягами даних**. Створюю застосунки з використанням **TypeScript, JavaScript, React, Node.js, REST API та PostgreSQL** — від аналізу вимог до реалізації, налагодження, тестування, інтеграції та розгортання.

Маю досвід керівництва командними проєктами, перевірки коду, координації роботи frontend- і backend-розробників та розв’язання технічних завдань на різних рівнях застосунку.

Маю **науковий ступінь PhD з фізики** та ґрунтовну підготовку в галузі обчислювальних методів, зокрема **Python, C, C++, чисельного моделювання, аналізу даних, машинного навчання й ШІ на основі Python**.
